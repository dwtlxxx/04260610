## 八、部署方式

本项目统一使用 **GitHub Pages** 发布，详细步骤见 [`docs/02-GitHub部署手册.md`](docs/02-GitHub部署手册.md)。

核心配置：

- **Source**：`Deploy from a branch`
- **Branch**：`main`　/　**Folder**：`/(root)`
- 站点地址：https://dwtlxxx.github.io/04260610/
- 站点入口：**仓库根目录的 `index.html`**
- 根目录已放置 `.nojekyll`，避免以下划线开头的目录被 Jekyll 忽略

### 方案 1 带来的目录硬约束

1. `index.html` 必须位于**仓库根目录**，它就是这个站点的首页
2. 所有资源引用必须用**相对路径**（`./css/style.css`），
   **严禁** `/css/style.css` 这类绝对路径 —— 会指向 `dwtlxxx.github.io/css/...` 导致 404、样式全丢
3. 页面间跳转同样使用相对路径（`./detail.html`）
4. 不引入任何构建步骤（不出现 `npm run build`），写什么就提交什么
